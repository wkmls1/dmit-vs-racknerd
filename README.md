## 二、线路才是真正的分水岭

DMIT 的产品线是按网络等级切的，不是按配置切的：

- **Premium（Pro）**：去程电信/联通走 CN2 GIA、移动走 CMI，三网回程全走 CN2 GIA。国内访问体验最稳，价格最高。

- **Tier 1（T1）**：纯国际 BGP，没有中国专项优化。它是 DMIT 全系里最便宜的一档，流量超出后不停机，降到限速继续跑。

RackNerd 的线路就一句话：普通国际 BGP，机房在洛杉矶、圣何塞、西雅图、达拉斯、芝加哥、纽约、亚特兰大、阿什本以及欧洲部分城市。它在中国大陆方向可能出现延迟抬升、绕路和晚高峰丢包，这也是社区里反复出现“RackNerd 只适合做落地，不适合直连国内”这类讨论的原因。

## 五、什么情况选 RackNerd，什么情况选 DMIT

**RackNerd 更合适：**

- 跑监控探针、RSS、定时任务、异地备份这类对延迟不敏感的服务
- 需要大量流量和大硬盘，但访问者主要在海外
- 学生、新手练手，或者单纯想要一台便宜的美国 IP 机器
- 多机房铺点，做冗余备用节点

**DMIT 更合适：**

- 网站面向中国大陆用户，首页加载速度直接影响跳出率
- 团队每天要跨境登录服务器后台，晚高峰卡顿消耗的是工时
- 建站需要 IP 质量和稳定性，不想被隔壁邻居的超售拖累
- 需要 DDoS 防护，或者需要香港、东京这种亚洲低延迟节点

社区里有一种被反复提到的用法：DMIT 做中转入口，RackNerd 做落地承载。两边互补，总成本仍然可控。这不是官方方案，实际部署前建议先把路由和合规问题想清楚。

- `Lite-Semi-Annually-Recur-20OFF`：Standard 系列半年付八折

需要说明的是，这些码来自第三方汇总，季节性促销码（比如圣诞活动那批）通常限时，过期就失效。下单前一定要在结账页用 Validate Code 实测一次，能打折再用，别默认它在。另外 DMIT 香港的 Lite 系列已经改名为 Standard，并且取消了 $6.90/月的最低款，老攻略里的套餐名可能已经对不上。

RackNerd 这边情况相反：本轮 VPS Specials 不需要优惠码，促销价直接下单。部分符合条件的订单可以在购买后提交信息申请双倍流量，但这不是默认配置，能否通过以官方处理结果为准。

还有几个容易踩的点：

- RackNerd 促销页没有明确写“续费价格”这行字，订单页显示为年付循环计费，但页面文字层面没有承诺。第一次续费前把账单看清楚。

## 七、常见问题

**只看价格，RackNerd 是不是更划算？**

单看每美元买到的 CPU、内存和流量，是。但 VPS 的实际成本不只是账单金额，还包括你因为网络波动多花的时间。如果你的业务对大陆访问有明显依赖，便宜的那台反而更贵。

**DMIT 的 T1 和 RackNerd 有什么区别，都是国际线路？**

T1 的机房、硬件平台和 DMIT 其他产品线一致，超额后限速不停机，端口带宽给得比较高（入门档就是 4Gbps）。RackNerd 的优势是同等预算下配置更高、流量更多、机房可选范围更广，以及更低的尝试门槛。

**可以先买一台试试吗？**

两家的付款周期都支持月付或年付，DMIT 部分套餐有季付。想验证线路，先用测试 IP 在晚高峰 ping 和 mtr，比先买后退更省事。
